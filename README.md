# AI Recommendation Logic

## Project Overview
A simple recommendation system developed as part of the DecodeLabs Artificial Intelligence Internship – Project 3.

The system takes user preferences, matches them with movie genres, calculates a similarity score, and displays recommendations.

## Features
- Takes user preferences as input
- Matches preferences with movie genres
- Calculates similarity score
- Displays recommended movies
- Ranks recommendations by similarity

## How It Works
1. User enters one or more preferred genres.
2. Preferences are compared with movie genres.
3. Matching preferences are identified.
4. A similarity score is calculated.
5. Movies are displayed according to their matching score.

## Similarity Formula

Similarity Score =  
(Matching Preferences / Total User Preferences) × 100
